How to get these keys?
1. Go to api.slack.com/apps → Create App
2. Go to OAuth & Permissions → Add scopes: channels:create, chat:write, users:read
3. Click Install to Workspace → Copy the Bot User OAuth Token
4. Scroll to Signing Secrets → Generate → Copy the Signing Secret

Webhook Setup (Required for Interactive Buttons)

So your bot can respond to button clicks in Slack

1. Go to Event Subscriptions in your Slack App

2. Enable Events → Set Request URL to:

/api/slack/webhook

4. Scroll to Bot Events → Add Bot User Event → Select message.channels
